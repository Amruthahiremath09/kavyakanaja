# ✍️ KavyaKanaja – Android App

A modern Android application designed for managing poems, stories, and creative works in an organized and user-friendly manner. It provides a smooth and efficient platform to create, store, and explore literary content with a clean interface and seamless performance.

---

# 🚀 Features

- 🔐 Secure login and logout system
- 👤 User profile creation and updates
- ✍️ Create, edit, and delete poems and stories
- 📚 Organized content library
- 🔍 Search and filter writings
- 📊 Professional dashboard with content overview
- 🗂️ Category based organization
- ❤️ Save favorites and bookmarks
- 🌐 Multi language support
- ⚙️ Settings and profile management
- 💾 Offline storage using local database
- ⚡ Fast and smooth performance

---

# 🛠️ Tech Stack

- **Language:** Kotlin or Java
- **Platform:** Android Studio
- **Database:** SQLite or Room Database
- **UI:** Material Design Components
- **Architecture:** MVVM

# ⚙️ Setup Instructions
## Or Download ZIP

 1. Open the project repository on GitHub.
 2. Click the **Code** button on the repository page.
 3. Select **Download ZIP** from the dropdown menu.
 4. Wait for the ZIP file to download completely.
 5. Locate the downloaded ZIP file in your system.
 6. Right-click the ZIP file and choose **Extract All** or **Extract Here**.
 7. Select the destination folder for extraction if needed.
 8. Open the extracted project folder to access the files.
## Import into Android Studio

1. Open Android Studio
2. Click **Open**
3. Select project folder
4. Wait for Gradle sync
5. Click **Run**
